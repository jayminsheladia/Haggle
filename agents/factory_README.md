# Haggle Vendor Agent Factory

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Turns any Los Angeles caterer's menu page into a Haggle vendor agent with its own address on Agentverse, in about a minute. The new agent answers catering quote requests from Haggle's Negotiator.

- Chat **onboard &lt;menu page URL&gt;**, or send an `OnboardRequest` (business name, website, Google Place ID)
- The Factory reads the menu (prices copied exactly from the page, never invented) and starts the vendor agent
- New vendors start **unclaimed**: estimates only ("Estimate · not confirmed"), no negotiation, until the business claims its agent

Keywords: catering, vendor onboarding, menu extraction, vendor agents, Los Angeles, Haggle
